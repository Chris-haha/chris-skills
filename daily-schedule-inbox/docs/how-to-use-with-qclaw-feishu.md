# 如何把这个 Skill 接到 QClaw / 飞书

## 你要交给它什么目录

把整个目录交给对方：

`daily/schedule/skills/daily-schedule-inbox/`

里面真正要保留的是：

- `SKILL.md`
- `scripts/schedule_inbox.py`
- `tests/test_schedule_inbox.py`
- `docs/`

`/.pytest_cache/` 这类运行缓存可以删掉，不影响使用。

## 你要先准备什么

1. 安装并能正常使用这个 `daily-schedule-inbox` skill。
2. 确认 QClaw 或飞书已经接好了对应的 MCP 能力。
3. 先说开场提示词，让系统知道你要它自动整理和提醒。
4. 确认提醒出口是 QClaw 还是飞书，或者两者都要。

## 你日常怎么操作

### 场景一：先说开场提示词

你直接写一行：

```text
我是自媒体创作者。请把我后续输入的每一句话都自动整理成任务、日程、复盘或提醒。你要自动判断优先级、时间、是否需要条件触发，并在合适的时候帮我触发外部消息提醒。不要让我自己操作文件、格式或流程。
```

系统会自动把它收进后续流程。

### 场景二：直接说具体事情

比如：

```text
周五之前把下周三条选题定下来
```

系统会自动把这句话归到任务、日程、复盘或提醒里，不需要你选格式。

### 场景三：后续继续说

你后面每补一句，系统都继续自动整理、归集和提醒，不需要你重新设置。

## 给 QClaw / 飞书之前要做的准备

1. 先决定提醒是走 `qclaw` 还是 `feishu`。
2. 约定好是否支持提前提醒，比如提前 30 分钟。
3. 约定好条件触发的命名方式，比如：
   - `brand_reply_received`
   - `draft_approved`
   - `stats_ready`
4. 约定好发送成功后是否把状态标记为已发送。

## 实际流程

### 1. 你先给系统一个开场提示词

比如：

```text
我是自媒体创作者。请把我后续输入的每一句话都自动整理成任务、日程、复盘或提醒。你要自动判断优先级、时间、是否需要条件触发，并在合适的时候帮我触发外部消息提醒。不要让我自己操作文件、格式或流程。
```

### 2. 你后续随口说一句话

比如：

```text
等品牌方回复报价后，再安排拍摄时间
```

系统会自动判断它是条件提醒。

### 3. 条件满足或时间到了

QClaw / 飞书会在合适时间自动发消息给你。

## 推荐的落地方式

### 如果你想先做最简单版本

- 只要用户说一句话，就自动记住
- 自动归类成任务、日程或提醒
- 到点就发

### 如果你想要更像助手

- 同时支持到点提醒和条件提醒
- 条件满足可以提前发
- 等待中的事项单独保留
- 所有后续输入自动归集，不需要用户重复配置

## 建议的消息节奏

- 当天要做的事情：早上推一次
- 临近截止的事情：提前推一次
- 条件型事情：条件满足时立刻推
- 每周复盘：固定在周末或周一早上推
