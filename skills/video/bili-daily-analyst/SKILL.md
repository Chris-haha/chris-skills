# B 站博主视频与口播分析

围绕用户指定的 B 站博主、视频或主题分析。技能不预置具体订阅对象和历史分析数据；不要自行新增订阅对象。分析一次性视频时无需建立定时任务；只有用户提出订阅或定时需求时才维护订阅和调度。

## 确定范围

从用户提供的空间链接、MID、昵称或视频链接确定对象；仅有昵称且不能唯一确定时，保存候选和核验来源并请用户确认，不要将同名账号视为已确认。询问必要的时间范围；对于每日定时任务，未指定时可建议北京时间 09:00，统计上次 09:00（含）到本次 09:00（不含），有用户约定则优先使用约定。了解用户希望关注的主题和分析深度，个人背景没有提供时不要凭空假定。

## 工作区与迁移

使用持久工作目录存放配置、报告、媒体、逐字稿和状态；执行 `python <skill>/scripts/bootstrap.py <工作区>` 可创建空目录及空名单，已有文件不会覆盖。用户给出订阅名单后填写工作区 `watchlist.json`：每个账号保存原始标识、平台昵称、MID、核验来源及状态；不确定则保留待确认。用户有排除名单时记录并在采集和报告中执行。生成物不写入 skill 文件夹。迁移流程及随附工具用法见 [运行指南](references/operation.md)。

## 分析流程

1. 根据用户指定的时间窗口，逐个核对账号身份与可见投稿，分页直到可证实覆盖窗口；使用视频详情复核作者 MID 和发布时间，按 BV 去重。搜索结果只作候选发现，无法证明穷尽。风控、分页不完整、零结果未经可靠覆盖等情形标记未确认，不声称无更新。记录账号覆盖、证据和错误。
2. 尽力获取每个视频的完整官方字幕；不可用时下载音频、本地转写。多 P 分别处理并记录 CID，媒体文件名固定，使用独立目录避免覆盖。核对时间范围、语音空段与尾部，必要时重试、听辨或 OCR；不要把转写抵达末尾等同于完整。标明来源、处理进度、缺失段和不确定性。失败与部分完成的视频要保存原因和下次重试状态。不根据标题或简介编造口播。
3. 依据已取得的内容整理作者、标题、链接、发布时间、转写来源和完整性，以及关键时间戳、主要论点、方法步骤或案例、适用场景及限制；根据用户给出的背景判断价值及是否值得深入。区分博主观点和独立核验事实；内容不全只分析已取得部分。
4. 按日期保存报告，不覆盖已有报告；保存逐字稿与可恢复状态。列出覆盖范围、身份待确认者、失败、遗漏风险和重试任务。失败不得阻断其他对象。一次性分析可按用户要求采用更简洁交付。

## 定时运行

用户明确要求定期执行时，用当前 Codex 支持的自动化工具配置任务，指定本机持久工作区和此技能；先检查已有任务避免重复。延迟运行时按计划日计算窗口，依据状态补查遗漏窗口和重试失败；无法判断计划日时说明假设。若时区、设备休眠或网络条件影响运行，说明限制。安装技能不会自动创建定时任务。
