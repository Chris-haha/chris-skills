# 资格与成绩协议

个人可报范围由当届官方规则与个人审核结果共同决定。此表是记录框架，不是资格认定器，不代替区中招办审核。

## 内部记录

只在任务需要时保存脱敏档案，不自动上传或长期保留未成年人资料。

| 字段 | 记录要求 |
| --- | --- |
| cohort_year | 参加中考的绝对年份，未知不自动填今年 |
| candidate_type | 应届/往届/其他；缺失为待确认 |
| hukou | 本人京籍与否、必要的区/资格类别，不记录证件号 |
| school_registration | 学籍省市/区；外省回京、转学、连续学籍情况按路径补充 |
| exam_district | 最终报考区、手续状态；居住区不能代替 |
| exam_registration | 初中学考报名及审核状态 |
| admission_scope | 分学校类型/批次记录可报、不可报、待确认；注明审核结论来自用户还是公开政策 |
| score_record | 考试类型、年月、原始总分/满分、科目、体育、加分；不合并不同考试 |
| rank_record | 年份、区、考试类型、群体和排名口径、来源，校排名单独保留 |
| policy_evidence | 官方标题/链接、适用届别、发布时间、查询日期、条款与局限 |
| preferences | 已提供的预算、通勤、住宿与路径接受度 |

每个结论标记：`用户提供`、`官方规则已核验`、`推断/预案`、`待确认`。用户提供的“审核通过”不是 Agent 已查询个人系统。

## 资格状态

- `eligible`：目标届别官方条件有依据，用户条件/审核反馈支持该路径，没有关键冲突。
- `ineligible`：有对应届别依据或明确审核结果证明该路径不可报；说明范围，不能扩大到所有升学路径。
- `pending`：条件、审核、手续或规则缺失/冲突；列缺口和核实渠道，不给该路径个人学校推荐。

成绩与政策准备状态另行判断。成绩高不能改变资格；户籍或学籍单项也不能替代整个资格判断。

## 特殊情形

- 非京籍：按官方类别逐项核对，不一刀切；学考报名成功不是普通高中升学资格。
- 京籍外省学籍/往届：核对当届报名审核、报考区、手续及批次限制，不照搬在京应届生路径。
- 户籍与学籍跨区：先确认选择及手续，再核对它对招生范围和指标分配的影响。
- 已有其他录取、直升或特殊项目安排：按需核对是否仍能参加后续志愿，不只看成绩。
- 当届规则尚无依据：保留待确认，历史政策仅作背景，不替未来规则作资格认定。

## 成绩比较边界

正式分数也要确认满分、科目和体育/加分口径。一模、二模、校考或估分只作规划，校内排名不是区排名。历史录取线必须标年份、批次、学校/专业及可信来源；政策、计分或招生规模变化时不可裸分横比。不做无依据的固定加减分换算。

缺排名时允许使用可追溯的同届分布、对应范围的历史资料等做解释性定位，写明不确定性；证据不支持冲稳保分档就不分档。所谓“保”只是相对风险判断，不等于保证。
