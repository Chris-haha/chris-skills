# 原始资料投喂区

放入已授权且不含秘密的需求、会议结论或其他材料，再请求 Agent 按 [维护规则](../AGENTS.md) 摄入。不能读取的格式应如实标记 pending，不假装解析成功。

摄入后原件留原地，通过 [来源账本](../sources.md) 的 partial/ingested/excluded 状态判断进度，不自动移动或删除。规范型材料保留其权威性质，摄入不能凭个人解释重新制定团队规范。

本目录原件默认被局部 `.gitignore` 忽略；知识页不被该规则忽略。分享原件前审查内容并遵循项目约定，忽略规则无法阻止 Agent 读取文件，也无法保护已跟踪的敏感文件。
