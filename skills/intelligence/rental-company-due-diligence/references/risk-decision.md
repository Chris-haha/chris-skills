# 风险判断

## 分开判断风险和证据

- **高风险**：已匹配主体的重大官方风险记录，或本次交易存在关键权限、资金去向等无法解释的缺口。单项重大问题足以建议暂缓，不用好评平均抵消。
- **需警惕**：存在有关联的负面线索、集中未退押金、异常变更或预付暴露，尚需补证。变更、低实缴、年轻公司均不能单独证明诈骗。
- **目前未发现显著风险**：关键主体与权限已核对、主要渠道有效覆盖、本次收款方案可核验，未见相反的重要证据。用这个有限表述，不能写“绝对安全”。
- **无法判断**：名称歧义、关键官方渠道缺失或材料严重不足。仍可针对个人码等具体方案建议不付款。

证据充分程度单列“较充分/部分/不足”，说明对哪个维度充分。社交传言很多也不代表身份充分。发现刑事判决时准确表述裁判认定对象与事项；警方立案不等于有罪判决。

## 历史记录、当前状态与页面冲突

为异常、执行、处罚分别保留发生/列入、移出/撤销/履行、查询时点三类时间。商业平台动态存在具体记录，但概览显示“自身风险0”时，两者都保留；可能是历史事件、已解决或统计口径差异，没有后续证据就写当前状态未知。不能凭标题“存续”或一个风险数字抵消具体事件，也不能凭旧动态声称今天仍在名单内。

只读到商业平台正文时写“该平台收录的历史线索”，不能表述为已由法院或监管原文确认的事实；找不到后续证明，也不能反向认定尚未履行或整改。

一般被执行不等于失信，执行标的不是租户受骗金额；同案重复动态去重，开庭和执行没有同案依据时不串成一条已证实因果链。公司更名、换股东、迁址不自动等于逃债，需要核对时间、承接及官方处置。

商业工商字段的横线不等于实缴0，认缴不等于已到位；年报参保0不等于实际员工0。公开查询0条不等于无备案或违法认定；押金托管签约名单有记录也不证明本次款项到账。上述差异应反映在证据充分程度和补证条件中。

## 交易检查与改变建议的条件

| 信号 | 检查与建议 |
|---|---|
| 合同甲方、品牌、收款方不同 | 核对每方身份、角色与书面授权；公司租赁业务要求打员工个人码且无法核验去向时暂缓。私人房东合法出租另行核对，不能一概将个人账户定性诈骗。 |
| 经纪公司要求代收租金押金 | 先确认实际业务角色及适用现行规则；在中国大陆核对条例第25条，不能用一张授权书就认定合法。经纪佣金与租金押金分开。 |
| 房屋非公司自有 | 核对产权与委托/转租授权、上游租期、业主确认方式；不动产权证照片本身不能证明当前授权。 |
| 半年付/年付换优惠 | 明确预付暴露；核对监管规则、账户及上游付款周期；没有上游凭据时标注未知，不能仅凭年付认定长收短付。 |
| 房东催欠租且仍催租户预付 | 查独立欠租记录、涉及房源和时间、官方处置；优先暂停新增付款评估，不擅自建议违反既有合同停租或转付。 |
| 集中退押纠纷、失联、关店 | 去重、确认主体、区分约定未到期/逾期、公司回复/真实退款，找最近进展。未证实仍可作审慎交易建议。 |
| 租金贷、信用分期 | 查贷款合同借款人、放款对象、退出后剩余还款义务；不要把“月付”当成没有负债。 |
| 集团背景、国企宣传、保函 | 查实际持股链、官方披露与担保文本；品牌授权不等于偿付担保，真实持股不证明一定兜底。 |
| 注销、吊销、重大执行/破产 | 确认当前状态、事件时间与交易主体；一般被执行、失信、终本、撤回和履行分别表述。 |

建议具体化：哪些文件由谁出示、通过什么独立渠道核验、哪些条款或付款方式要调整，以及哪项未满足前暂缓。不能用“自行核实”四字代替行动清单。已付款用户先保留合同、收据、沟通与退款约定，并核查当地正式求助渠道；不承诺追回款项。

付款暴露示例（纯假设）：月租3000，预付6个月，押金3000，无其他费用，未入住时已付暴露21000；入住一个月且未退款时，未履行租金15000加押金3000为18000。未发生损失前不称损失18000；如租金贷已支付同笔租金，不再把贷款本金重复相加，而是单列剩余偿债义务。
