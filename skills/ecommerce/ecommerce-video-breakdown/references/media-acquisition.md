# 匿名媒体取材

Skill自带三平台分享页读取、身份核对、字幕读取、媒体下载、本地语音识别、关键帧和缓存代码。取材实现位于 scripts/public_media.py，字幕格式读取位于 scripts/subtitle_formats.py，输入及隔离任务入口位于 scripts/upstream.py；这些文件均随包分发，不导入其它Skill或应用项目。

## 取材顺序

- 小红书保留完整分享地址和访问参数，从本次匿名页面的 noteData 同时读取笔记ID、作者、正文、可得互动数据与视频地址。页面未返回目标笔记或ID不一致时停止，不能用其它笔记补位。
- 抖音展开分享链接，再读取匿名移动分享页中与目标视频ID匹配的数据，保留作者ID和实际视频地址。
- B站核对视频ID和CID，读取完整字幕正文；字幕不可用时尝试公开音轨与本地转录。在线只接受单P视频，显式非首P或接口返回多P时先停止，不借用其它分P字幕。B站WBI参数依照平台协议生成。
- 平台全文字幕优先；需要下载器时使用 yt-dlp，支持 VTT、SRT、JSON3 和 XML/TTML。部分字幕下载失败时仍检查已经保存的有效字幕。标题、正文和平台摘要不能代替逐字稿。
- 没有字幕时，只使用已准备好的本地 faster-whisper 或 whisper.cpp 模型，不在解析中联网补模型，不套用纠错词库改写识别结果。
- 获取原视频后用 FFprobe 读取真实时长，再均匀抽取六帧。取得画面但没有可靠口播时，保留视频和关键帧供画面分析；不能把页面正文改成口播。

## 匿名约束

不读取Cookie文件、浏览器Cookie、账号配置、已登录浏览器或云端转录。下载器始终使用 --ignore-config，参数限制为随包流程使用的字幕和媒体操作，拒绝账号、Cookie、请求头与用户配置注入。分享地址含账号凭据、页面身份不符或匿名访问被拒绝时，记录失败并使用用户提供的本地资料。

## 归档、缓存与迁移

新链接用 ingest；已有目录用 import --source 导入。博主以平台账号ID区分，同名不合并。短长链接只在解析结果能证明同一视频时归并。

媒体、缓存、日志和运行配置只写入指定工作区 parser-state 等目录，不写Skill源码。缓存保留同次请求取得的身份和正文数据；实际媒体时长与帧时间戳一起保存，不用页面整数时长重算。缓存过期或引用文件缺失时重新取材。已归档的旧工作区无需重复解析，数据格式和后续报告流程保持兼容。

分享参数和媒体临时地址只保存在本地运行资料，公开成品脱敏。分发包不携带运行资料、凭据、模型或环境。首次初始化与跨系统配置见 [runtime.md](runtime.md)。
