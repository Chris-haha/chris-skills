# 产品物理真实性与支撑关系锁设计

## 问题

现有产品一致性清单能锁定部件、连接、功能结构和使用状态，却不能显式记录物体受重力后的稳定姿态。第四张图因此满足了“勺杆穿过杯盖缺口”，却把长勺画成水平悬空：勺头在杯内，棕色球端伸出杯外但没有支撑。

## 目标

每次生图前必须说明产品及配件在当前场景中的重力方向、支撑点、接触关系和稳定静置姿态。任何无支撑悬空、违背重力、穿透实体或不稳定摆放都禁止生成，并在交付前判定失败。

## 方案

在 `ProductIdentity` 中增加必填元组 `physical_constraints`。`product-identity.md` 新增“物理与支撑关系”区块；CLI 新增可重复参数 `--physical-constraint`。

直接生图提示词将该字段作为硬约束，要求区分“手持/运动中”和“无人支撑的静置状态”：手持部件必须明确由手支撑；静置部件必须由桌面、杯壁、杯盖、卡槽或其他真实接触面支撑。不得让物体水平悬空、违反重力、穿透实体或处于明显会滑落/翻倒的姿势。

网页交接清单增加逐项物理核对。无特殊摆放要求的产品也必须显式填写“所有可见物体遵循重力并由真实接触面稳定支撑”。

## 错误处理

- `physical_constraints` 为空：报“物理与支撑关系不能为空”，禁止生图。
- 清单格式缺少该区块：加载失败。
- 生成结果出现无支撑悬空或不稳定姿态：保留失败图，只重做当前图片。

## 测试

- 新字段可在 Markdown 中完整往返。
- 缺少或为空时验证失败。
- 提示词包含物理关系清单及无支撑悬空禁令。
- Web 交付清单包含重力、支撑、接触和稳定性核对。
- CLI 缺少 `--physical-constraint` 时失败，提供后正确持久化。
