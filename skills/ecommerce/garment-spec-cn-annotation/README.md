# garment-spec-cn-annotation v3

这是修正版。重点新增：

1. **防乱码**：渲染前校验新增批注，若含乱码、日文假名、明显未翻译英文，会直接报错。
2. **防漏翻**：Skill 明确要求先做完整翻译清单，再统一检查翻译覆盖率。
3. **防原文照抄**：新增批注必须以简体中文为主，不能把日文/英文原样贴到图上。
4. **推荐输出 QA 报告**：便于检查有没有漏翻。

## 推荐指令

> 使用 garment-spec-cn-annotation v3 skill 处理这张规格书。先建立完整的非中文识别清单，再翻译成简体中文，并把中文用蓝字标在原文附近。不要覆盖原文、线条、尺寸和其他批注。禁止乱码，禁止把日文/英文原样贴成批注，禁止漏翻需要翻译的项目。输出 PNG、annotations.json 和 qa_report。


v3 新增：两阶段执行、翻译覆盖率硬门槛、原文伪翻译检测、字体完整性要求、区域复检、QA 报告硬门槛、独立 validate_annotations.py。
