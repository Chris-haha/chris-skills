# 电商合成质量修复协议

本协议用于商品替换已经完成、但合成图仍有模糊、糊纹、过度平滑、噪点或锐化痕迹时的后处理。固定优先级为：**产品事实 > 模特与场景不变量 > 接触与遮挡正确性 > 可验证的纹理质量 > 锐利感与摄影风格**。更清晰、更精致或更有电影感，均不能补偿商品身份、人物身份或场景事实的变化。

修复只能改善来源中已有但呈现不佳的信号，不能恢复来源从未记录的证据。像素不足、遮挡或单一角度造成的未知信息必须保持未知；不得把推测出的纹理、缝线、logo、五金或文字称为“恢复”。

本协议中的“QA 通过”仅是阶段检查，不自动授予商业状态；商业执行仍受[manifest 方法能力与交付闸门](fidelity-manifest.md)约束。质量修复后旧 QA 失效，更新 manifest 并重新验证；`verified_composite` 是像素复用验证状态，`verified_reference_match` 是证据约束自然重建状态且不表示像素相同。后者必须重新通过 `material_identity_fact_ids` 对应的 `qa.material_comparison`，纹理、光泽、挺括度、缝线或五金反射任一漂移均拒绝。

## 1. 先诊断退化

在原始文件和实际交付尺寸下检查，不要仅凭缩略图或放大后的主观锐利感判断。

| 退化类型 | 识别依据 | 允许的最小处理 | 边界与停止条件 |
|---|---|---|---|
| 来源像素不足 | 关键边缘只占少量像素；放大后没有可重复验证的结构 | 请求更高分辨率原图或局部特写；必要时仅做尺寸适配 | 不声称恢复缺失证据；不得生成身份关键细节 |
| 压缩损伤 | 块状、蚊噪、色带或边缘台阶与编码网格一致 | 局部去块、去蚊噪、轻量去色带 | 不把压缩伪影误认成材质纹理，也不以锐化放大伪影 |
| 生成式纹理糊化 | 皮革、织物、头发或皮肤呈涂抹状，纹理方向断裂或重复 | 只在已诊断区域做受参考约束的局部质量编辑 | 若需要重画产品结构、脸或背景才能“变清晰”，拒绝该方法 |
| 过度平滑 | 皮肤、织物或材质缺少来源可见的微小起伏与色调变化 | 轻量恢复局部微对比和来源支持的纹理层次 | 禁止美容化、假毛孔、统一噪声或凭空增加材质颗粒 |
| 锐化伪影与光晕 | 高反差边缘两侧出现亮边、暗边、振铃或锯齿 | 降低锐化、局部去晕、回退到较早版本 | 不用二次锐化掩盖；边缘拓扑或轮廓发生变化即拒绝 |
| 色度噪声与彩色斑点 | 中性暗部、皮肤或平滑材质出现随机红绿蓝斑点 | 优先做低强度色度降噪，保留亮度结构 | 不改变商品色、肤色、环境色或材质反射色 |
| 有意景深或运动模糊 | 模糊随焦平面、距离、运动方向或快门轨迹连续变化 | 保留；仅修复叠加其上的压缩、色噪等独立缺陷 | **不得锐化有意模糊**，也不得把离焦区域重绘成虚假的清晰细节 |

诊断无法区分“缺失信息”和“呈现缺陷”时，按缺失信息处理：停止生成式补细节并请求更好的来源。

## 2. 输入来源角色

每次质量修复前显式分配角色，禁止让模型自行推断来源用途。

| 角色 | 唯一职责 | 不得提供的内容 |
|---|---|---|
| `TARGET_SCENE` | 人物身份、身体与姿势、构图、透视、背景、原始光线、景深、运动模糊和接触位置 | 新商品的结构或纹理事实 |
| `PRODUCT_TRUTH` | 商品身份的唯一视觉事实：轮廓、比例、材质、颜色、纹理、缝线、logo、文字、五金和连接拓扑 | 人物或背景的重设计依据 |
| `DETAIL_TRUTH` | 解释 `PRODUCT_TRUTH` 中指定局部的补充近照或其他角度 | 未展示区域的推断；不得扩展为整件商品的新设计 |
| `COMPOSITE_INPUT` | 已通过产品保真验收、等待质量修复的基础合成图 | 新的产品事实；不得因它看起来完整就覆盖原始参考 |
| `GEOMETRY_PROXY`（可选） | 只约束宏观姿态、体积、折叠走向和大尺度空间关系 | 颜色、材质、纹理、缝线、logo、文字、五金、边缘细节或连接拓扑 |

`COMPOSITE_INPUT`、`GEOMETRY_PROXY`、任何生成候选和任何修复输出都永远不能升级为 `PRODUCT_TRUTH`。后续版本仍须携带原始 `PRODUCT_TRUTH`，必要时同时携带 `DETAIL_TRUTH`。

## 3. 分阶段工作流

1. **先完成商品替换。** 按产品事实表、连接拓扑和场景不变量生成或合成 `COMPOSITE_INPUT`，此阶段不以“增强质感”为借口扩大重绘。
2. **先通过产品保真验收。** 商品身份、人物、背景、光线、构图、接触和遮挡未通过时，不进入质量修复。
3. **记录单一诊断。** 标出缺陷类型、证据、位置、允许修改的遮罩和预期改善；提示词中只列真实观察到的缺陷。
4. **单独执行最小范围质量处理。** 默认直接编辑 `COMPOSITE_INPUT` 的局部；修复与替换必须是两个可比较、可回退的阶段。
5. **重新执行全部 QA。** 质量处理后重新检查商品、人物、场景、光线/景深、边缘/接触和输出元数据，不能沿用修复前的通过结论。
6. **A/B 决策。** 把修复版与修复前版本在等效显示尺度并排比较。只有已诊断缺陷明显改善，且没有商品身份、人物身份或场景漂移时才保留修复版；否则回退。

## 4. 方法选择

| 方法 | 适用条件 | 约束 | 决策 |
|---|---|---|---|
| 直接局部“只修质量”编辑 | 默认方法；缺陷可定位且基础合成已通过产品保真 QA | 最小遮罩、原始参考同时输入、禁止重画产品/脸/背景；一次只修一种退化 | 优先 |
| 确定性缩放、降噪、去块、去晕或轻锐化 | 工具可用，且缺陷属于采样、编码或可测噪声 | 参数可复现；先保守处理再 A/B；锐化不得作用于有意模糊或放大不存在的证据 | 可作为收尾 |
| 线稿、泥模或白模代理 | 仅当宏观姿态、体积或折叠需要额外控制，且原始参考足以证明所有会显露的身份细节 | 代理是有损几何提示，不是产品事实；非默认；先做一张试片；受控遮罩；修复时必须同时提供 `TARGET_SCENE`、`PRODUCT_TRUTH` 和相关 `DETAIL_TRUTH` | 谨慎、可选 |

若只有一个商品角度，而代理流程会显露、补画或重新解释未知的身份关键细节，**拒绝代理流程**。请求相应角度或局部特写，或调整遮挡与构图使未知区域继续不可见。

## 5. 指令质量规则

- 默认完整保留来源的相机几何、画面范围、构图、透视、景深、背景布局、光线方向、颜色关系和整体氛围。
- 只允许在商品边缘、真实接触区和接触投影内做必要的局部匹配；遮罩应是能解决缺陷的最小区域，不得借机重做全局光影或背景。
- `Sony A1`、`85mm`、光圈、ISO、快门等相机或曝光词不是质量保证。它们只可在从零创建场景时作为可选视觉速记，不能写成事实性的拍摄声明，也不能代替清晰的像素、材质与保真要求。
- 把“4K”改写为工具实际支持的明确像素尺寸并保持原始宽高比。例如工具支持长边 `3840 px` 时，短边按 `round(3840 * 原短边 / 原长边)` 计算，并按工具要求取合法整数；若工具采用其他 4K 规格，应写出该确切尺寸。扩大分辨率只改变采样尺寸，不会恢复缺失细节。
- 只有读取并核验实际输出文件元数据后，才能声称 `10-bit` 或其他位深；提示词、文件名和视觉观感均不能证明位深。
- “精确保留原光线”与“新增暖高光、冷阴影等重新布光”相互矛盾。默认由保留要求胜出；只有用户明确要求独立的重布光版本时，才另开版本处理，并重新做完整 QA。
- 使用可观察语言描述缺陷、位置和允许变化，不使用“超高清”“电影级”“完美细节”等无法验收的堆叠形容词。

## 6. 质量目标与禁止项

### 可验收目标

- 商品材质具有与来源一致的特定反射行为和纹理尺度，例如皮革的方向性纹理、金属的受控高光、哑光涂层的柔和反射；不得用通用“高级质感”替代。
- 来源支持的接缝、轮廓和边缘可读，宽度、走向、数量和连接关系不变。
- 皮肤保留自然微纹理、细微色调变化和真实高光过渡，不美容化。
- 头发具有发束、细丝和碎发的层级，不能变成塑料片、均匀线条或重复纹理。
- 织物保留来源支持的织纹尺度、褶皱层级、张力方向和遮挡关系。
- 微对比与颗粒保持克制，只用于恢复来源支持的层次；不能让噪声或锐化感成为“清晰”的替代品。

### 禁止项

蜡感、塑料感或陶瓷感皮肤；美容化；假毛孔；过度平滑；光晕、振铃与过锐；重复纹理；摩尔纹；色彩噪点；凭空增加缝线、颗粒、logo、五金或文字；虚假镜头光晕；背景变化。任何新增、删除、复制、改色、改材质、改比例或改连接方式的商品变化均按产品身份漂移拒绝。

## 7. 提示词合同

### 直接质量修复：`QUALITY PASS ONLY`

```text
TASK
QUALITY PASS ONLY. 以 COMPOSITE_INPUT 为唯一编辑底图，只修复下方列出的已诊断质量缺陷。
这不是商品替换、人物重绘、背景重绘、重新布光或创意风格化任务。

REFERENCE ROLES
- COMPOSITE_INPUT: 已通过产品保真 QA 的编辑底图；保留其全部内容和像素位置关系。
- TARGET_SCENE: 人物身份、身体、姿势、构图、透视、背景、原光线、颜色、景深和运动模糊的事实来源。
- PRODUCT_TRUTH: 商品身份的唯一视觉事实来源。
- DETAIL_TRUTH: 只验证所标注的商品局部；不得推断未展示区域。

DIAGNOSED DEFECTS - REPAIR ONLY THESE
- [缺陷类型]: [精确位置/遮罩]；证据 = [可观察现象]；目标 = [可验收改善]。

ALLOWED EDIT REGION
- 只修改 [最小遮罩或坐标描述]。
- 允许在该区域内做保守的去块、色度降噪、去晕、纹理层次恢复或微对比调整，且仅限上方诊断所需。
- 商品接触阴影只可在维持原光线方向和接触关系所需的最小范围内匹配。

PRESERVE EXACTLY
- 保留商品的轮廓、比例、颜色、材质、纹理尺度、缝线、logo、文字、五金、部件数量和连接拓扑。
- 保留人物身份、脸部结构与表情、皮肤色调、头发、身体、手指、服装和姿势。
- 保留相机几何、画面范围、构图、透视、背景布局与内容、光线方向、颜色关系、氛围、景深、运动模糊、水印和文字。

FORBIDDEN
- 不得重画、重新设计或替换商品；不得改变人物或面部身份、人物几何、身体外观与解剖比例、表情、发型、姿势或服装结构。人物与背景区域只允许在上方声明的最小遮罩内修复已诊断且由来源支持的纹理；不得扩展到遮罩外，也不得生成来源中不存在的纹理。
- 不得改变、扩展或替换背景内容与布局，也不得全局清理背景；不得新增暖高光、冷阴影、镜头光晕或其他重新布光。
- 不得锐化有意景深或运动模糊，不得发明缺失细节，不得新增缝线、颗粒、logo、五金、文字或假毛孔。
- 未由 PRODUCT_TRUTH / DETAIL_TRUTH 证明的区域保持遮挡、模糊或不变。

OUTPUT
- 保持原始宽高比；输出尺寸 = [工具实际支持的明确宽 x 高像素]。
- 生成一个可与 COMPOSITE_INPUT 直接 A/B 的候选版本，不覆盖原文件。
```

### 受控几何代理修复：`GEOMETRY_PROXY`

```text
TASK
以 COMPOSITE_INPUT 为编辑底图，在 [最小遮罩] 内恢复已诊断的 [缺陷]。
GEOMETRY_PROXY 只控制宏观姿态、体积和折叠走向；所有身份与外观事实仍来自原始参考。

REFERENCE ROLES
- COMPOSITE_INPUT: 已通过产品保真 QA 的基础合成；除最小遮罩外保持不变。
- GEOMETRY_PROXY: 有损的宏观几何控制，只提供姿态、体积、折叠和大尺度空间关系；不提供任何产品身份、材质或细节事实。
- TARGET_SCENE: 人物/面部身份、身体、姿势、构图、透视、背景、原光线、颜色、景深、运动模糊和接触位置的唯一场景依据。
- PRODUCT_TRUTH: 商品轮廓、比例、颜色、材质、纹理、缝线、logo、文字、五金、部件数量和连接拓扑的唯一事实依据。
- DETAIL_TRUTH: 只解释 [指定局部]；不得扩展到不可见部分。

DIAGNOSIS AND SCOPE
- 已诊断缺陷 = [一个缺陷及其可观察证据]。
- 允许修改 = [最小遮罩] 内为纠正该缺陷所需的像素。
- 代理允许控制 = [一个宏观几何变量，例如折叠走向或整体体积]。
- 其余像素、几何、光影和内容全部锁定。

RESTORATION RULES
- PRODUCT_TRUTH 管辖商品身份，TARGET_SCENE 管辖人物与背景身份；两者都高于 GEOMETRY_PROXY，代理只能在二者共同允许的范围内约束宏观几何。
- 商品材质和细节必须从 PRODUCT_TRUTH / 指定 DETAIL_TRUTH 恢复，绝不从线稿、泥模、白模或生成候选推断。
- 未知或单角度无法证明的身份关键细节必须继续被遮挡、离焦或保留原状，不得显露或补画。
- 只允许按原光线方向在商品边缘、接触区和接触投影内做最小匹配。

FORBIDDEN
- 不得把 GEOMETRY_PROXY、COMPOSITE_INPUT 或任何生成输出当作产品事实。
- 不得改变商品结构、连接拓扑、logo、文字、五金、颜色、材质或纹理尺度。
- 不得重画脸、皮肤、头发、手、身体、服装或背景；不得改变构图、透视、景深、运动模糊、颜色关系和氛围。
- 不得增加假细节、假锐度、假毛孔、重复纹理、全局锐化、镜头光晕或重新布光。

OUTPUT
- 只生成一张试片，保持原始宽高比，尺寸 = [工具实际支持的明确宽 x 高像素]。
- 保存为新版本并与无代理版本 A/B；仅当诊断缺陷改善且商品、人物、场景均无漂移时保留。
```

## 8. 多尺度 QA

必须使用同一色彩管理与缩放算法，并把候选图、`COMPOSITE_INPUT`、`TARGET_SCENE` 和产品原图并排检查。不存在适用于所有图片的“通用锐度分数”；应在等效显示尺度比较来源实际支持的细节，而不是奖励更强的边缘对比。

| 检查尺度 | 主要问题 | 必查项 |
|---|---|---|
| 适配画布/构图视图 | 整体是否漂移，修复是否改变视觉关系 | 商品尺度与位置、人物姿势与身份、背景布局、构图、透视、光线方向、颜色、景深与运动模糊 |
| `100%` 像素视图 | 身份和材质是否真实且有证据 | 商品轮廓、比例、纹理尺度、缝线、logo、文字、五金与拓扑；脸部身份、皮肤、头发、手指与身体解剖；材质反射、织纹、褶皱；商品边缘、遮挡、接触点和接触阴影 |
| `200%` 伪影检查 | 是否产生像素级副作用，不以此尺度评价整体美感 | 光晕、振铃、锯齿、重复纹理、摩尔纹、色噪、块状、涂抹、假毛孔、边缘漏色、遮罩接缝和文字/logo 破坏 |

最终还要核验输出文件：像素宽高与宽高比、色彩空间/ICC（若流程要求）、文件格式、alpha（若要求）以及实际位深。未读取到的元数据记为“未验证”，不能按提示词或文件名推断。

## 9. 重试与停止规则

- 每次重试只改变一个变量：一种处理方法、一个参数、一个遮罩或一句约束。记录变更和结果，不堆叠提示词。
- 所有候选使用版本号保存，例如 `quality-v01`、`quality-v02`；不得覆盖修复前的 `COMPOSITE_INPUT` 或上一候选。
- 若连续两次出现商品、人物或场景身份漂移，停止当前生成式方法，改用更确定的局部合成/处理或请求更好的原始参考。
- 若同一模糊缺陷连续两次没有改善，停止继续加锐或追加“高清”形容词；重新诊断其是否属于像素不足或有意模糊，并更换方法或请求更高分辨率来源。
- 一张试片完成完整 QA 并通过 A/B 决策前，不得批量处理。试片依赖代理或用户确认过的关键结构时，应先获得确认再扩展到整组。
- 任何修复若只提升表面锐利感，却降低产品事实、人物/场景不变量、接触关系或自然纹理，应立即回退并判为失败。
