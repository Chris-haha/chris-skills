# 素材制作、来源与复用

先按视觉任务列素材，再收集或生成。真实界面用截图／录屏证明具体操作与结果；类比用插画建立场景；机制图用可编辑SVG／React对象表达关系。示意界面必须标注，生成图不能作为产品实际功能的证据。录屏需要在项目组件中实现播放；当前默认recipe只内置图片聚焦和图层视差。

## assets.json实际契约

文件位于工程根目录；`schemaVersion:1`为登记格式，`assets`中的ID唯一。素材文件放`public`内，path相对public，解析后不得逃逸public或指向不存在的文件。当前编译器会验证全部登记素材，包括未被shot使用者；清理失效登记。

```json
{
  "schemaVersion": 1,
  "assets": [
    {
      "id": "checkout-screen",
      "path": "captures/checkout.png",
      "kind": "image",
      "purpose": "实际借阅界面中读者与书本的关联结果",
      "source": {"type": "project", "uri": "local-capture:checkout-session"}
    },
    {
      "id": "library-scene",
      "path": "illustrations/library.png",
      "kind": "image",
      "purpose": "说明书架与借阅台的空间关系，属于场景插画",
      "source": {
        "type": "generated",
        "uri": "generation:library-scene-01",
        "prompt": "暖象牙白背景、石墨轮廓、钴蓝书本与橙色借阅卡；同一书本B-017在借阅台；无文字、无遮挡的平面插画",
        "generationAttempts": 1
      }
    }
  ]
}
```

purpose、source.type和source.uri不可空。generated还需要完整prompt与generationAttempts≥1，记录实际尝试次数，不把重试隐去。建议另外保存服务／模型／运行ID、参考图、采集时间与许可信息供追溯；这些扩展信息不是当前编译器强制字段。kind使用image或video等实际类型作登记，当前编译器不检查kind枚举或解码内容，渲染时仍须核对格式、尺寸与损坏。

`media:screen`要求至少一个引用素材的source.type是project或original，这只是最低来源检查，不能证明它真是截图。uri应可追溯到实际采集对象或本地来源，不能把生成界面标为original绕过检查。其他来源可如实记录source.type和可访问页面；不要捏造授权。登记与路径检查不代替使用权限判断。

## 统一插画而保留对象

一页风格板约定色板、轮廓、材质、光源、透视、对象尺度、背景留白与标签规则。给对象命名并保存参考图，同一对象跨图使用一致轮廓和主色。生成复杂中文字容易漂移，优先生成无字主体，再以可编辑文字叠加准确标签。产品／品牌外观以用户素材为依据。

全局禁用通用机器人头、天线笑脸、聊天气泡头像作为“AI”的替身，不生成这类素材，也不从图标库挑选。按本期语义选择人物在做什么、实际任务、反馈稿件或成果；禁止一套图标配白卡片充满全片。素材生成提示词明确这些排除项，并实际打开选中图片复核。栅格图内部的图标、文字或关系线不能靠DOM结构检查发现，仍须逐张检查。版式、关系与状态规则遵循[visual-quality.md](visual-quality.md)。

运动需要分层时分别生成背景、透明对象、前景遮挡，保持相同相机与光源。记录每次生成prompt、重试及选中原因；不为了凑镜头数重复同一整图推拉。素材缺失或生成服务不可用时可推进稿件、分镜与工程结构，但不能把空白占位当作最终素材。

## 截图与录屏

从实际项目采集操作前／动作中／操作后证据，保存源分辨率、来源标识和关键状态。裁掉无关浏览器边框时保留解释需要的上下文。把标题和字幕留在独立层，镜头聚焦时别把正文缩到无法阅读。录屏避开个人数据与凭证；按真实片段选择适合当前旁白的区间，记录任何删减或速度变化。

素材检查至少包括实际像素、透明通道／裁边、缩放后可读性、多个镜头中的对象一致性和与口播事实的对应。编译器将资产文件哈希写入compiled-storyboard，用于标明本次使用的字节；图像审美、真实来源和语义准确仍需看画面。便携工程交付素材文件及manifest，避免只链接某台机器的临时目录。
