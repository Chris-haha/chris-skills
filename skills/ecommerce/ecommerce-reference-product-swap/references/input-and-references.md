# 当前任务的素材与参考接收

## 启动引导

先复用当前会话已有信息，只补问缺项：“请提供这次要替换的商品实拍与细节图，以及你有权使用的主图或详情参考图；参考按你希望的顺序上传即可。”用户已给商品图时只补问参考，已有参考时只补商品事实。不要重复索取已提供资料。

素材可来自对话附件、用户指定文件或明确授权读取的位置。不要自动下载竞品、从安装目录／其他库补模板。用户只说“沿用之前方式”时沿用流程，不默认复用旧商品或人物；先请其指定本次参考。

## 分开来源

| 类型 | 决定内容 | 记录 |
|---|---|---|
| 商品事实 | 当前形制、真实颜色、必要视角、尺寸与文案依据 | 原图、来源ID、哈希、缺口 |
| 编辑参考 | 版式、上传顺序、人物、场景及保留区域 | 用户原图、编号、哈希、可用范围 |
| 生成候选 | 当前待审阅输出 | 版本、提示词、源图角色与实际观察 |

原件保持不变，工作资料放用户独立任务目录，不能写进Skill包。以上传顺序或用户明确顺序为准，文件名不决定顺序。

## 使用范围与缺口

请用户提供有权使用的参考，说明是否需要且可以保留人物、品牌及版式；其说明作为素材来源声明，不伪造成法律授权证明。范围不明时可先整理商品事实、计划和缺口，暂不直接复刻；改用用户新参考或明确转入原创设计方案。

没有参考图不启动参考换图，没有必要商品视角不猜结构。缺素材或工具如实说明，不用占位图、旧案例或其他商品参数冒充输入。

## 本次计划

记录main/sku/detail范围、各组有序参考、主图张数、SKU风格位置、详情是否每色独立模特、品牌、保留／替换项、尺寸与目录。无人物参考不凭空造人，明确要求各色上身展示时逐色落实。

参考不足先协商调整计划、补上传或复用本次底图；任何补屏需记录真实底图、新增用途和事实来源，保留原详情相对顺序。
