# 产品可见连接证据锁设计

## 问题

第五张首版的棕色球端悬空，第二版降低球端后又把金属连接头与勺杆完全遮没。语义清单仍写着“球端固定连接勺杆”，但最终画面把球端表现成了独立摆件。

现有工作流分别检查部件数量、关系、物理支撑和使用状态，却没有要求关键连接关系必须在最终画面中留下可追踪的视觉证据。遮挡因此可以吞掉连接段，而文字层面的“属于同一把勺子”仍被错误判定为通过。

## 目标

新增必填的“可见连接证据”锁。每个关键连接链必须说明最终画面要看到的连接头、连续段、入口/出口边界或其他唯一归属证据。不能仅凭语义或相邻位置推断连接。

## 数据与接口

ProductIdentity 新增必填元组 visible_connection_evidence。product-identity.md 新增“可见连接证据”区块；CLI 新增可重复参数 --visible-connection-evidence。缺失或空值时，提示“产品一致性清单的可见连接证据不能为空”并阻止生成。

## 生成约束

直接生图提示词在“连接与从属关系”之后输出任务专属证据，并加入通用规则：

- 关键连接链必须能从一个可见端点连续追踪到所属主体。
- 遮挡允许隐藏中段，但遮挡前后必须出现匹配的入口/出口方向，或显示真实连接头、套环、铰链、接缝等证据。
- 不得让杆、线、带、把手或连接头在遮挡边界前凭空终止。
- 相邻、相切或叠放不能冒充固定连接。
- 如果构图无法证明连接，就调整角度或增加同一产品的局部特写，不能猜测或批准。

## 质检

网页交接包要求按“端点 → 连接件 → 连续段 → 遮挡入口/出口 → 所属主体”逐段追踪。出现连接链中断、端点消失、连接件缺失、遮挡边界方向矛盾或部件看似可独立移动时，必须硬失败。

第五张中央勺子的具体证据链为：棕色球端 → 银色连接套环 → 至少一段可见连续银色勺杆 → 杯盖开放式 U 形缺口 → 杯内。球端即使接触杯盖，也不能遮掉套环和全部勺杆。

## 验证

增加数据模型、Markdown 往返、缺失/空区块、CLI 必填、直接提示词和网页质检回归测试。先确认测试因字段缺失而失败，再实现最小改动并运行完整测试套件。
