# 检索与来源

## 渠道矩阵

| 维度 | 优先入口 | 关键核验 |
|---|---|---|
| 登记及变更 | [国家企业信用信息公示系统](https://www.gsxt.gov.cn/)；注册地市场监管局 | 信用代码、存续、曾用名、异常及移出日期；企业年报为申报信息 |
| 信用及处罚 | [信用中国](https://www.creditchina.gov.cn/)；当地住建、市场监管公告 | 文号、原因、日期、整改和撤销状态 |
| 执行与失信 | [中国执行信息公开网](https://zxgk.court.gov.cn/)；法院公告 | 代码匹配、执行案号、金额、进展；失信与一般执行分开 |
| 裁判和破产 | [中国裁判文书网](https://wenshu.court.gov.cn/)；[全国企业破产重整案件信息网](https://pccz.court.gov.cn/)；属地法院 | 当事人角色、判决结果、生效及履行情况；公开记录非全量 |
| 行业资质及资金 | 房源所在城市政府官网、住建/房管部门租赁平台 | 开业/备案主体、业务类型、风险名单、现行资金监管规则及开户验证方式 |
| 消费投诉 | 黑猫投诉、消费保等公开页面；公开12315/12345统计或回复 | 投诉原文、双方回应、退款凭据和时间；投诉平台不是裁判机构 |
| 体验与舆情 | 地图及租房平台评价、小红书、抖音、微博、知乎、贴吧、地方论坛、新闻 | 原帖可访问性、所在城市/门店、事件日期、独立性与后续 |
| 商业查询补充 | 企查查、天眼查、爱企查、水滴信用等公开页面 | 展开工商表、曾用名、变更及历史动态；标注来源与更新时间，能查原始记录则回查 |

这些是入口，不是已完成查询。每次重新记录实际访问状态，不把历史403、超时或登录限制挪作本次结果；可公开读取的商业平台详情不能替代官方当前状态。

## 查询扩展示例

将变量替换为已确认主体；不要将用户身份证、银行卡或私人合同全文发给搜索引擎。

- `“公司全称”`、`“信用代码”`、`“曾用名” 租赁`、`“品牌” “城市” “门店”`
- `“公司全称” 押金`、`退租 退款`、`拖欠 房东`、`关店 失联 跑路`、`租金贷`、`长收短付 高进低出`
- `“公司全称” 判决 执行 失信 破产`、`处罚 风险提示`、`开业信息 备案 监管账户`
- `site:gov.cn “公司全称”`、`site:court.gov.cn “公司全称”`；按当地政府真实域名补查
- `site:tousu.sina.com.cn “品牌” “城市”`、`site:xiaohongshu.com “品牌” 押金`，以及平台公开搜索。站内搜索或索引无法访问要记录，不能假装搜遍平台。
- `“品牌” 退款 已退 回应 澄清 整改`；正面评价、运营信息、门店持续经营及集团授权核对。

对每个关键主体使用身份查询、风险查询与后续查询三类词。查询结果稀少或明显无关时，应换实际搜索引擎或站内搜索补足；中国大陆公司优先补查可用的中文搜索入口（如百度、360、搜狗，按当次可访问性选择），不在同一个后端反复改词后宣称查遍全网。搜索引擎换了，原始来源没变，仍只算同一份证据。不要把搜索建议、AI摘要、推荐词中的“跑路”“不退押金”当作真实投诉。

工具未披露搜索后端时标记“独立性未知”，不凭工具品牌推断独立，也不猜测它们必定相同；可实际访问明确的搜索引擎或来源站点补查。

发现同代码曾用名时回查旧名的处罚、案件和投诉，不把用户最初给的旧名直接纠正为“错误名称”。法人、股东、门店和人员只作为有依据的扩展线索：优先核对变更日期、原经营主体和履约承接，不根据同名自然人归属案件，不把诉讼对手列为关联企业。用户未指定时，以主要主体与本次交易为边界；不无限扩散所有股东和全部关联企业。

## 访问失败与有效查询

按阻碍类型选择补查，不要求机械重试每个网站：

| 观察 | 下一步 | 能得出的结论 |
|---|---|---|
| 阅读工具超时，但有官方导航或搜索结果直链 | 普通浏览器打开真实来源，按导航找到查询页；保存成功或失败证据 | 该工具失败，尚不能判定整个网站不可用 |
| 搜索索引有公司页，原始URL已过时或指向登录 | 可以正常点击公开搜索结果，检查最终域名、页面正文和主体代码；若仍需登录则停止 | 确实读到正文才记“已读”；不能把索引摘要升级成正文 |
| 公开政府入口连接异常 | 核对域名及公开页面提供的现用入口；若存在同域公开HTTP入口，可仅用于无凭据、无个人资料的公开查询并记明协议 | 不将HTTP当通用降级方案；不关闭证书校验，不换代理、伪造身份或绕验证码 |
| 可打开查询表单 | 用全称与辨识度较高的关键词分别查；按实际业务角色区分经纪机构、租赁企业、押金托管及处罚入口 | 打开页面、填写未提交、查询词被忽略均不算有效查询 |
| 返回0条或结果与条件无关 | 检查查询条件是否保留、是否刷新及结果总数；必要时用该页已公开的一条记录作阳性对照，确认筛选生效 | 有效0条仅说明该入口、该条件、该时点无匹配，不能直接认定未备案或无违法 |
| 登录、验证码、安全校验、付费墙 | 记录阻碍，改查其他合法公开渠道或请用户提供脱敏查询结果 | 未核验，不能记0条；不突破限制或反复刷新 |

浏览器查询留存：入口、实际最终URL、查询字段和值、提交方式、查询时间、结果总数、原文/截图、入口范围与限制。不记录Cookie、会话标识等非必要字段；阳性对照企业仅用于验证筛选，不作为被调查企业的关联证据。

浏览器交互采用“观察页面→定位字段/按钮→操作→等待预期结果→重新观察”的循环。导航或表单变化后重新定位，不复用失效元素；等待结果表、条件回显或总数更新，而非只等固定秒数。使用独立临时浏览器上下文，避免接管用户已有登录页或其他任务窗口；只读查询不代表有权保存、提交投诉或操作账户。

对公示名单、公告附件、营业执照照片，阅读实际图片/表格，不只读页面标题。先核对主体名称及信用代码；看不清的字段标为待核实。旧执照与新工商表不一致时查变更，不把旧照片当最新状态。页面顶部与详细表格不同，保留两者并标注冲突。

## 检索路由与可选工具

为每个关键缺口选择下一个最有区分力的查询：身份不清先查代码/旧名，退押争议先找原帖和后续，历史案先追案号及处置。初始长查询没有召回时拆成单个主题词；不要把“多个词同时命中”当作每个维度都已覆盖，也不为填满矩阵机械访问所有引擎。

规划工具（Python标准库，无网络请求）：

```bash
python3 scripts/prepare_research.py --name "公司全称" --city "城市" --former-name "曾用名" --credit-code "信用代码" --engines 360,baidu,bing
```

从技能目录运行；在其他目录使用脚本绝对路径。不知道的可选字段省略；可重复传 `--former-name`。输出为JSON，或用 `--output` 指定一个尚不存在的文件；不会覆盖已有证据。所有链接初始状态都是 `planned`，`collection_performed=false`，不能直接作为检索台账交付。`backend_family`只是目标服务的分组标签，不证明结果独立。

实际执行时另记：查询ID、目标引擎、实际后端（未知则注明）、原始来源、执行时间、最终URL、结果访问状态、取得的证据ID、下一步。将路线标为完成必须确实取得结果或明确限制。无必要不访问所有生成链接；不要把未打开链接记为无记录。

新增能力按需选用：现有浏览器/网页工具优先；agent-browser等需安装时先检查现有能力；博查等API仅在已配置且获准使用时调用，企查查Connector仅在工具实际可用时调用。Skill说明、工具名称清单或环境变量名称不等于已接通数据，缺依赖就保留公开渠道路线和缺口，不要求用户先购买服务，不记录密钥。

## 覆盖与停止条件

正常尽调的最低交付范围是这些维度的结果或真实缺口，不能只写搜到的几项：

- 工商与变更：身份代码、曾用名、法人/股东、登记迁移、异常及后续。仅有房源页时继续找企业详情。
- 住建与资金：按角色查询备案/开业信息和当地适用的托管/监管信息，明确“企业签约名单”不同于“某笔资金已入账”。
- 司法与行政：沿实际发现的案号、文号、日期、机关追原文和处理进展；具体号仍检索不到就保留商业平台线索，不能补写案情。
- 投诉与舆情：全称、曾用名、品牌和已证实门店线索；区分投诉原帖、转载、平台“暂无记录”和站内未能查询。
- 本次交易：授权、签约主体、收款与付款周期；未提供材料时明确无法核验，不阻止其他维度的研究。

停止条件：各维度已有可追溯的结果，或在适用的替代公开路径尝试后仍有明确阻碍；重大矛盾已补查或列待核实；不同来源路径不再带来新主体/事件。单一引擎连续两轮重复不是结束理由，也不强求固定搜索次数。用户时限优先；到时交付初筛和待办，不以等待用户材料为由放弃已可独立完成的调查，不承诺“全网查无风险”。

## 官方规则基线：每次调查仍须复核现行文本

[国务院《住房租赁条例》（住建部原文）](https://www.mohurd.gov.cn/gongkai/fdzdgknr/zfhcxjsbwj/gkzhudongfalvfagui/gkzhudongfagui/art/2025/art_023ede16314441768380b60c7344be90.html)，2025-07-21发布，2025-09-15施行，2026-11-02开发时已读取：第19条涉及转租经营企业的监管账户；第25条包含经纪机构代收代付租金押金的禁止性规定。研究时应确认适用范围、现行效力及配套办法，不自行编造全国统一的付款月数阈值。

[张家港住建局风险提示](https://www.zjg.gov.cn/zjg/zffw_zxxx/202507/8bee4d118abf4ec585f5ef408489ecb9.shtml)，2025-07-25发布，2026-11-02开发时读取，说明高进低出、长收短付风险；作为风险机理来源，不据此认定特定企业采用该模式。其他城市须核查各自规定。
