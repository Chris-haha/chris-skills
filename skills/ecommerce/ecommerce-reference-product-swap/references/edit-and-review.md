# 参考编辑与逐图审阅

用户本次参考决定版式、原人物（如有）、姿态、场景和元素位置；当前商品原资料决定形制、颜色、部件、纹理和参数。生成图只辅助风格／人物核对，不证明商品事实。不同原人物逐屏保留，无人物参考不新增人；缺所需视角保留编号与缺口，不通过改原姿态或猜结构规避。

## 每张提示词

```text
Use case: identity-preserve（有人物）/ precise-object-edit（静物）
第一张：用户本次指定的当前屏编辑底图；其余：当前商品原始事实图。
任务：只换指定商品，保持原比例、构图和文字层级。
保留：当前参考可见的人物身份、表情姿态、接触、场景、道具、光线、裁切；静物不新增人。
替换：只写实拍支持的形制、颜色、部件、纹理与参数。
文案：逐字列本品有据标题、数字、单位及本次品牌处理。
禁止：旧商品结构、材质、检测值和服务承诺；编造不可见部件；更换人物场景或把整套合成一张。
输出：对应当前编号的单张成品；保留原参考已有拼贴，不擅自新增视图。
```

本地原图先查看，真实通过工具参数传入，提示词仅写路径不算传图。保存完整请求、图角色、哈希、输出尺寸、版本与具体观察；未知实际模型名记unknown。内置能力无须中转Key，持续失败保留已完成屏和缺口，不用占位图冒充。每轮修订聚焦问题、重复保留项，先看首屏再继续。

## 审阅

1. 商品：有据颜色、形制、部件数量、连接、纹理、使用状态、尺寸，未知视角不补。
2. 人物／场景：原身份、姿态、手指归属、物件、光线、裁切；无人物如实not_applicable。
3. 版式：编号与参考绑定、照片占比、文字层级和比例，不统一强改。
4. 文字／品牌：对本次来源，移除旧品牌与无据承诺，记录具体观察。
5. 整套：不漏、合、重排原屏；补屏有本次指定底图与事实来源，单图长图同序，覆盖完整颜色。

detail_model_policy=per_color时，每色至少一张独立单色模特图（asset_role=model、has_person=true、单色id且商品／人物QA通过）；服装须真实上身，背景有人、平铺、多色合图不替代。not_required用于本次无独立模特要求，不得降级用户已明确的模特需求，也不免除原有人物的保留与审阅。

来源与可用范围不由图像工具代为授予；不能视旧图人物、标志或摄影为随Skill获得授权。文件数、哈希、尺寸和长图区段只证明导出一致，最后仍须实际浏览器核对入口、全部单图、总览、长图、刷新，记录URL、版本、时间、桌面／手机截图并亲自查看。
